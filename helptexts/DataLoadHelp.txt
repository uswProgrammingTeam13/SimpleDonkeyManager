[데이터 불러오기 도움말]

1. 폴더 선택
- 우측 하단의 [폴더 선택] 버튼을 클릭하여 이미지 데이터가 저장된 폴더를 선택합니다.
- 지원 형식 : .jpg, .png, .bmp
- 선택한 폴더 내 이미지 개수, 해상도, 파일 크기 정보가 자동 표시됩니다.

2. 데이터 로드
- [데이터 로드] 버튼을 클릭하면 이미지 목록이 좌측 패널에 로드됩니다.
- 이미지가 많을 경우 로딩에 시간이 소요될 수 있습니다.

3. 이미지 선택
- 좌측 이미지 리스트에서 원하는 이미지를 선택할 수 있습니다.
- [이미지 전체 선택] 체크 시 모든 이미지를 한 번에 선택합니다.
- 검색창을 이용하여 특정 이미지 파일명을 검색할 수 있습니다.

4. 프레임 이동 및 재생
- 중앙 화면에서 선택한 이미지 또는 프레임을 확인할 수 있습니다.
- [이전 프레임], [다음 프레임] 버튼으로 프레임 이동이 가능합니다.
- [재생] 버튼을 누르면 이미지가 순차적으로 재생됩니다.
- 배속 조절 기능으로 재생 속도를 변경할 수 있습니다.
- [정지] 버튼으로 재생을 멈출 수 있습니다.

5. 데이터 필터링
- 상단 [데이터 필터링] 메뉴에서 특정 조건의 이미지만 추출할 수 있습니다.
- 파일명, 해상도, 형식 등의 조건을 기반으로 필터링 가능합니다.

6. 학습 실행
- 상단 [학습 실행] 버튼을 클릭하여 선택한 데이터셋 기반 학습을 진행합니다.
- 학습 전 데이터 선택 상태를 반드시 확인해 주세요.

7. 학습 결과 확인
- [학습 결과 확인] 메뉴에서 학습 결과 및 로그를 확인할 수 있습니다.
- 오류 발생 시 실행 로그 내용을 먼저 확인해 주세요.

8. 실행 로그
- 하단 실행 로그 창에는 프로그램 동작 상태 및 오류 메시지가 출력됩니다.
- 데이터 로드 실패 또는 이미지 오류 발생 시 로그 내용을 참고하세요.

[주의사항]
- 손상된 이미지 파일은 정상적으로 로드되지 않을 수 있습니다.
- 대용량 데이터셋 사용 시 메모리 사용량이 증가할 수 있습니다.
- 학습 중 프로그램을 강제 종료하지 마십시오.

[권장 사항]
- 데이터셋은 클래스별 폴더 구조로 관리하는 것을 권장합니다.
- 동일한 해상도의 이미지를 사용하는 경우 학습 안정성이 향상될 수 있습니다.
