[개요]
학습 실행 탭에서는 로드된 데이터(필터링 후 또는 전체)를 사용하여 
Donkeycar 자율주행 모델을 학습시킵니다.

[데이터 상태 확인]

학습을 시작하기 전에 화면 상단의 "데이터 상태" 패널에서 
학습에 사용될 데이터 정보를 확인할 수 있습니다:

  • 데이터 폴더: 학습에 사용될 이미지와 메타데이터가 있는 폴더 경로
  • 프레임 수: 학습에 사용될 전체 이미지 개수
  • 필터링 여부: 데이터 필터링 적용 여부 표시
	(필터링 O: 필터된 데이터로 학습, 필터링 X: 전체 데이터로 학습)

[모델 유형 선택]

학습할 모델 유형을 선택합니다. 각 모델은 다른 특성을 가지고 있습니다:

  • Linear (선형 모델)
	직선 주행 및 부드러운 곡선 주행에 최적화되어 있습니다.
	장점: 학습 빠름, 메모리 효율적, 간단한 모델
	권장: 처음 시작하거나 리소스가 제한된 환경

  • Categorical (분류 모델)
	다양한 각도의 복잡한 경로 주행에 최적화되어 있습니다.
	장점: 여러 방향 처리, 정확도 높음
	권장: 복잡한 경로나 여러 주행 스타일 학습

  • 3D CNN (3D 합성곱 신경망)
	시간 시퀀스를 고려한 고급 학습으로 최고 정확도를 제공합니다.
	장점: 최고 정확도, 동적 환경 대응
	권장: 고성능이 필요하고 학습 시간 및 리소스가 충분할 때

[모델 저장 경로 설정]

1. "📁 모델 저장 경로 선택" 버튼을 클릭합니다.
2. 학습된 모델을 저장할 폴더를 선택합니다.
   (폴더가 없으면 자동으로 생성되고, 각 학습마다 고유한 파일명으로 저장됩니다)
3. 경로가 선택되면 텍스트 필드에 표시됩니다.

[학습 시작 및 진행]

1. 위의 모든 설정을 확인한 후 "③ 학습 시작" 버튼을 클릭합니다.

2. 학습이 시작되면:
   • 진행도 바: 현재 학습 진행률을 표시합니다 (%)
   • 진행 텍스트: 현재 진행 중인 작업을 표시합니다
   • 로그 패널: 실시간으로 학습 로그가 표시됩니다

3. 학습 중에는:
   • 기존 설정을 변경할 수 없습니다.
   • "■ 학습 중지" 버튼으로 학습을 중단할 수 있습니다.
   • 로그에서 실시간 진행 상황을 확인할 수 있습니다.

4. 학습 완료 시:
   • 진행도 바가 100%에 도달합니다.
   • 모델 파일이 지정된 폴더에 저장됩니다.
   • 로그에 "학습 완료" 메시지가 표시됩니다.

[학습 로그 확인]

화면 하단의 "실행 로그" 패널에서:

  • 에포크(Epoch) 진행도: 현재 진행 중인 에포크와 전체 에포크 수 표시 (예: "Epoch 5/50")
  • 손실값(Loss): 모델의 학습 손실값 (값이 낮을수록 좋음)
  • 검증값(Validation): 검증 데이터셋에서의 성능
  • 에러 메시지: 학습 중 발생한 문제를 표시합니다

[학습 완료 후]

학습이 완료되면:

  1. "④ 학습 결과 확인" 탭에서 학습 결과를 분석합니다.
	 (학습 곡선 및 성능 지표 확인, 모델 저장 위치 확인)

  2. 추가 학습이 필요한 경우:
	 학습 설정을 조정한 후 다시 학습을 시작합니다.
	 (이전 모델을 덮어씌우거나 다른 경로에 저장 가능)

[팁]

  • 처음 학습할 때는 Linear 모델로 시작하여 성능을 평가한 후 
	더 복잡한 모델로 업그레이드하세요.

  • 학습 데이터가 많을수록 (1000개 이상 권장) 더 좋은 모델을 얻을 수 있습니다.

  • 학습 중 로그를 주시하여 비정상 동작이나 에러를 빨리 발견하세요.

  • 모델 저장 경로는 접근 가능한 로컬 폴더를 권장합니다 
	(네트워크 드라이브는 느릴 수 있음).
