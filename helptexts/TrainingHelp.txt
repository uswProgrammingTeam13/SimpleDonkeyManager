# 도움말

## 1. 학습 설정
좌측 학습 설정 패널에서 학습에 필요한 옵션을 설정할 수 있습니다.

- 모델 선택
  사용할 AI 모델을 선택합니다.

- 데이터 경로
  학습에 사용할 데이터셋 경로를 지정합니다.

- 이미지 크기
  입력 이미지의 해상도를 설정합니다.
  일반적으로 120x160, 224x224 등의 크기를 사용합니다.

- 배치 크기(Batch Size)
  한 번에 학습할 데이터 수를 설정합니다.
  값이 클수록 메모리 사용량이 증가할 수 있습니다.

- 에포크(Epoch)
  전체 데이터셋 반복 학습 횟수를 설정합니다.

- 학습률(Learning Rate)
  모델 가중치 업데이트 속도를 설정합니다.
  너무 크면 학습이 불안정해질 수 있습니다.

- 조기 종료(Early Stopping)
  성능 향상이 없을 경우 자동으로 학습을 종료합니다.

- Patience
  성능 향상이 없을 때 몇 Epoch까지 기다릴지 설정합니다.


## 2. 학습 진행 상태
중앙 상단의 학습 진행 상태 패널에서는 현재 학습 상태를 확인할 수 있습니다.

- 진행률
  전체 학습 진행 상태를 표시합니다.

- 현재 Epoch
  현재 진행 중인 학습 반복 횟수를 표시합니다.

- 현재 단계
  데이터 로딩, 전처리, 학습 등 현재 작업 상태를 표시합니다.

- 데이터 사용량
  학습 중 사용 중인 데이터 정보를 표시합니다.

- 남은 시간
  학습 완료까지 예상 남은 시간을 표시합니다.

- 경과 시간
  학습 시작 후 지난 시간을 표시합니다.

- 예상 완료 시간
  학습이 완료될 것으로 예상되는 시간을 표시합니다.


## 3. 이미지 미리보기
우측 이미지 미리보기 패널에서는 데이터셋 이미지 및 프레임 정보를 확인할 수 있습니다.

- 현재 선택된 이미지 또는 프레임이 표시됩니다.
- 프레임 번호 및 전체 프레임 수를 확인할 수 있습니다.
- 조향 값(Angle)과 속도 값(Throttle) 정보를 표시합니다.

### 프레임 제어 기능
- 이전 프레임
  이전 이미지로 이동합니다.

- 재생
  이미지 프레임을 자동 재생합니다.

- 일시정지
  재생을 잠시 멈춥니다.

- 다음 프레임
  다음 이미지로 이동합니다.

- 배속 조절
  재생 속도를 변경할 수 있습니다.


## 4. 학습 로그
중앙 하단의 학습 로그 패널에서는 프로그램 실행 상태와 로그를 확인할 수 있습니다.

- 데이터 로드 상태
- 학습 진행 로그
- 오류 및 경고 메시지
- 모델 저장 상태

오류 발생 시 로그 내용을 먼저 확인해 주세요.


## 5. 학습 제어
좌측 하단의 학습 제어 패널에서 학습을 직접 제어할 수 있습니다.

- 시작
  학습을 시작합니다.

- 일시정지
  현재 학습을 일시 중단합니다.

- 중지
  학습을 완전히 종료합니다.

- 초기화
  설정 및 상태를 초기화합니다.


## 6. 상단 메뉴 기능

### 데이터 불러오기
학습에 사용할 데이터셋을 불러옵니다.

- 지원 형식 : .jpg, .png, .bmp
- 데이터 개수 및 정보가 자동으로 표시될 수 있습니다.
- 대용량 데이터셋은 로딩 시간이 길어질 수 있습니다.

### 데이터 필터링
특정 조건에 맞는 데이터만 선택할 수 있습니다.

- 파일명 기반 검색
- 이미지 크기 필터링
- 형식별 필터링

### 학습 실행
현재 설정된 데이터와 옵션으로 AI 학습을 시작합니다.

학습 실행 전 아래 항목을 반드시 확인해 주세요.

- 데이터 경로
- 모델 설정
- 학습 파라미터

### 학습 결과 확인
학습 완료 후 결과를 확인할 수 있습니다.

- 학습 정확도
- 손실 그래프
- 저장된 모델 정보
- 실행 로그


# 주의사항

- 손상된 이미지 파일은 정상적으로 로드되지 않을 수 있습니다.
- 대용량 데이터셋 사용 시 메모리 사용량이 증가할 수 있습니다.
- 학습 중 프로그램을 강제 종료하지 마십시오.
- 학습 설정 변경 후에는 다시 학습을 시작해야 적용됩니다.


# 권장 사항

- 동일한 해상도의 이미지를 사용하는 것을 권장합니다.
- 데이터셋은 폴더별로 정리하여 관리하는 것이 좋습니다.
- 학습 전 데이터 필터링을 통해 불필요한 이미지를 제거하면 성능 향상에 도움이 될 수 있습니다.
- 학습 결과는 주기적으로 저장 및 백업하는 것을 권장합니다.
