                    데이터 필터링 (Data Filter)
═══════════════════════════════════════════════════════════════

[개요]
데이터 필터링 탭에서는 로드된 이미지 데이터에서 학습에 필요하지 않은 
프레임을 제거하기 위한 다양한 필터를 적용할 수 있습니다.

───────────────────────────────────────────────────────────────
[기본 필터 설정]
───────────────────────────────────────────────────────────────

• 이미지 크기 (Image Size)
  로드된 이미지의 해상도를 표시합니다.
  필터링 시 선택된 크기에 맞지 않는 이미지를 제거할 수 있습니다.

• 각도 범위 필터 (Angle Filter)
  ✓ 체크: 각도 범위 필터 활성화
  - 범위: 최소값 ~ 최대값 (도 단위)
  - 설정된 범위 내의 각도를 가진 프레임만 유지
  - 예: 0° ~ 45° 범위 설정 시, 이 범위 밖의 프레임 제거

• 스로틀 범위 필터 (Throttle Filter)
  ✓ 체크: 스로틀 범위 필터 활성화
  - 범위: 최소값 ~ 최대값 (%)
  - 설정된 범위 내의 스로틀 값을 가진 프레임만 유지
  - 예: 20% ~ 80% 범위 설정 시, 해당 범위의 가속도 데이터만 학습에 사용

• 비활성화 프레임 제거 (Remove Disabled Frames)
  ✓ 체크: 비활성화된 프레임 제거
  - 학습에서 제외된 것으로 표시된 프레임을 필터링에서 제거

───────────────────────────────────────────────────────────────
[추가 필터 옵션]
───────────────────────────────────────────────────────────────

• 제거된 프레임 삭제 (Delete Filtered Frames)
  ✓ 체크: 필터링되지 않은 프레임만 유지
  - 필터 조건에 맞지 않는 프레임을 완전히 삭제
  - 체크 해제: 필터링된 프레임을 비활성화만 (나중에 복구 가능)

• 제거된 프레임 강조 표시 (Highlight Deleted Frames)
  ✓ 체크: 필터링될 프레임을 미리보기에서 강조 표시
  - 빨간색 또는 특별한 표시로 제거될 프레임을 시각적으로 표시
  - 필터 적용 전 결과를 확인할 수 있습니다

───────────────────────────────────────────────────────────────
[필터 결과 요약]
───────────────────────────────────────────────────────────────

• 총 프레임 수 (Total Frames)
  데이터 로드 시 읽은 전체 프레임 개수

• 필터링 후 프레임 수 (Filtered Frames)
  현재 필터 설정을 적용했을 때 유지될 프레임 개수

• 제거된 프레임 수 (Removed Frames)
  필터링으로 제거될 프레임 개수 및 제거 비율

• 활성 프레임 비율 (Active Frame Ratio)
  전체 대비 유지될 프레임의 백분율
  - 높을수록: 더 많은 데이터로 학습 (일반성 높음)
  - 낮을수록: 선별된 고품질 데이터로 학습 (정확도 높음)

───────────────────────────────────────────────────────────────
[동작 버튼]
───────────────────────────────────────────────────────────────

• 필터 미리보기 (Preview)
  현재 필터 설정을 적용했을 때의 결과를 이미지 뷰에서 미리 확인
  - 왼쪽: 필터링될 프레임 목록
  - 중앙: 선택된 프레임의 원본 이미지
  - 우측 하단: 필터 결과 요약

• 필터 초기화 (Reset)
  모든 필터 설정을 기본값으로 복원
  - 모든 체크박스 해제
  - 범위값을 초기값으로 변경

• 필터 적용 (Apply Filter)
  현재 설정된 필터를 최종 적용
  - 학습 데이터를 준비하는 단계로 진행
  - 이후 학습 탭에서 모델 학습을 시작할 수 있습니다

───────────────────────────────────────────────────────────────
[사용 팁]
───────────────────────────────────────────────────────────────

1. 먼저 미리보기로 필터 결과를 확인한 후 적용하세요.

2. 활성 프레임 비율이 너무 낮으면 (10% 미만) 학습 데이터가 
   부족할 수 있으니 필터 조건을 조정하세요.

3. 각도와 스로틀 범위는 데이터셋의 특성에 맞게 조정하세요:
   - 곡선 주행 학습: 큰 각도 범위 (±45° 이상)
   - 직선 주행 학습: 작은 각도 범위 (±15° 이내)

4. 비활성화 프레임이 많은 경우, 제거 옵션으로 데이터셋 크기를 
   줄여 학습 속도를 향상시킬 수 있습니다.
