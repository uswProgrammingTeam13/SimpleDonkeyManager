				  SimpleDonkeyManager - 시작 가이드
═══════════════════════════════════════════════════════════════

[환영합니다]
SimpleDonkeyManager는 Donkeycar 자율주행 자동차 프로젝트의 학습 
데이터를 효율적으로 관리하고 처리하기 위한 도구입니다.

[프로그램 구조]

SimpleDonkeyManager는 4단계의 워크플로우로 구성됩니다:

  1️⃣  데이터 불러오기 (Data Load)
	 데이터 폴더를 선택하고 이미지 & JSON 메타데이터를 로드합니다.
	 폴더 통계 (이미지 수, 크기, 해상도) 확인 및 이미지 프레임 미리보기

  2️⃣  데이터 필터링 (Data Filter)
	 로드된 데이터에서 학습에 불필요한 프레임을 제거합니다.
	 각도, 스로틀, 이미지 해상도 등으로 필터링 후 미리보기

  3️⃣  학습 실행 (Training)
	 선택한 데이터로 Donkeycar 모델을 학습시킵니다.
	 Linear, Categorical, 3D CNN 중 선택 가능

  4️⃣  결과 확인 (Result)
	 학습된 모델의 성능을 분석하고 학습 곡선을 확인합니다.

[시작하기]

다음 단계를 따르세요:

  1. 화면 상단의 "① 데이터 불러오기" 버튼을 클릭합니다.

  2. 데이터 폴더를 선택하고 로드합니다.
	 폴더에는 record_000.jpg, record_000.json 형식의 파일이 필요합니다.
	 시스템이 자동으로 이미지와 메타데이터를 스캔합니다.

  3. 로드된 데이터를 확인한 후, 필요시 "② 데이터 필터링"으로 진행합니다.
	 (필터링은 선택사항이며, 필터 없이 바로 학습할 수도 있습니다)

  4. "③ 학습 실행"으로 모델을 학습시킵니다.
	 모델 유형과 저장 경로를 설정하고 학습을 시작합니다.
	 "④ 학습 결과 확인"에서 결과를 확인합니다.

[필요한 환경]

  • .NET 10 Runtime
  • Python 3.11 이상
  • Donkeycar 라이브러리 (pip install donkeycar)

자세한 설치 방법은 DEPLOYMENT_GUIDE.md를 참조하세요.

[팁]

  • 화면 하단의 실행 로그에서 각 단계의 진행 상황을 확인합니다.
  • 이미지 미리보기와 메타데이터 정보로 데이터 품질을 사전에 확인하세요.
  • 필터링 미리보기를 활용하여 학습에 사용될 정확한 데이터를 확인하세요.
  • 학습 완료 후 모델은 지정한 폴더에 자동 저장됩니다.

더 자세한 정보는 각 단계의 도움말을 참고하세요!
