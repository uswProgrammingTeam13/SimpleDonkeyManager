───────────────────────────────────────────────────────────────
[학습 성능 지표]
───────────────────────────────────────────────────────────────

• 훈련 손실값 (Training Loss)
  학습 중 모델의 손실값 변화
  - 값이 낮을수록 학습이 잘 진행됨
  - 그래프가 우하향할수록 수렴이 잘 진행됨

• 검증 손실값 (Validation Loss)
  검증 데이터셋에서의 모델 성능
  - 훈련 손실과의 차이가 작으면 과적합(Overfitting) 가능성 낮음
  - 차이가 크면 더 많은 데이터나 규제 필요

• 에포크별 성능
  각 에포크(학습 주기)별 손실값 추이

───────────────────────────────────────────────────────────────
[모델 평가]
───────────────────────────────────────────────────────────────

학습된 모델의 품질을 판단하는 기준:

✓ 좋은 모델의 특징
  • 훈련 손실이 0.01 이하로 낮음
  • 검증 손실이 훈련 손실과 유사
  • 학습 곡선이 안정적으로 수렴
  • 에포크가 진행될수록 손실이 감소

⚠ 주의해야 할 신호
  • 훈련 손실과 검증 손실의 큰 차이 (과적합)
  • 손실값이 감소하지 않고 진동
  • 특정 에포크 이후 성능이 악화
  • 학습 초기부터 손실이 증가

[결과 활용]
───────────────────────────────────────────────────────────────

1. 모델 배포
   • 생성된 .h5 파일을 Donkeycar 프로젝트로 복사합니다.
   • Donkeycar에서 이 모델을 사용하여 자율주행을 시작합니다.

2. 모델 개선 (성능 부족 시)
   • 데이터 재필터링
	 - 새로운 필터 조건으로 학습 데이터 재선택

   • 데이터 수집 추가
	 - 더 많은 학습 데이터를 수집한 후 재학습

   • 모델 유형 변경
	 - Linear → Categorical → 3D CNN 순서로 시도

   • 하이퍼파라미터 조정
	 - 배치 크기, 에포크 수 등을 변경하여 재학습

3. 비교 분석
   • 여러 모델을 학습하여 성능 비교
   • 각 모델의 장단점 분석
   • 실제 자율주행 테스트를 통한 검증

[FAQ]
───────────────────────────────────────────────────────────────

Q: 손실값이 계속 증가합니다. 뭐가 문제인가요?
A: 다음을 확인하세요:
   • 학습률이 너무 높지 않은지 확인
   • 데이터가 정상적으로 로드되었는지 확인
   • 메모리 부족으로 인한 문제가 없는지 확인

Q: 훈련 손실과 검증 손실의 차이가 큽니다.
A: 과적합이 발생할 수 있습니다:
   • 더 많은 학습 데이터 수집
   • 모델의 복잡도 조정
   • 규제(regularization) 강화

Q: Linear 모델과 Categorical 모델 중 뭘 사용해야 하나요?
A: 데이터와 용도에 따라:
   • 직선 주행 중심: Linear
   • 복잡한 경로 (S자, 원형): Categorical
   • 매우 정확한 동작 필요: 3D CNN
